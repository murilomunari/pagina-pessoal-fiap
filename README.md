# Landing Page Pessoal 

Este projeto consiste na criação de uma **Landing Page pessoal**, desenvolvida com o objetivo de apresentar de forma clara e visual minhas habilidades, conhecimentos e projetos.

Uma **Landing Page** é uma página web focada em concentrar informações importantes em um único local, permitindo que visitantes conheçam rapidamente quem sou, quais tecnologias utilizo e alguns dos trabalhos que já desenvolvi.

---

## Objetivos do Projeto

- Praticar estruturação de páginas com **HTML**
- Trabalhar estilização utilizando **CSS**
- Criar interações com **JavaScript** (menu mobile, accordion e botão voltar ao topo)
- Criar uma **Landing Page pessoal**
- Aplicar uma **paleta de cores definida**
- Organizar o projeto para publicação no **GitHub**

---

##  Paleta de Cores

A landing page utiliza a seguinte identidade visual:

| Tipo | Cor |
|-----|-----|

---

##  Estilo

- Border Radius padrão: **10px**
- Layout simples e responsivo
- Foco em **legibilidade e organização visual**
